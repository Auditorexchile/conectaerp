# Íconos del Sistema

Esta carpeta contiene los íconos SVG del sistema.

## Íconos recomendados:

- dashboard.svg
- ventas.svg
- compras.svg
- inventario.svg
- contabilidad.svg
- reportes.svg
- configuracion.svg

## Alternativa:

El sistema está diseñado para usar emojis o Font Awesome como íconos.
No es necesario agregar archivos SVG si usas una de estas opciones.
