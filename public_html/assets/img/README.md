# Imágenes del Sistema

## Archivos requeridos:

- **logo.png** - Logo principal (fondo oscuro)
- **logo-white.png** - Logo blanco (fondo claro)
- **dashboard-preview.png** - Preview del dashboard para portada

## Especificaciones:

### logo.png
- Tamaño recomendado: 200x50px
- Formato: PNG con transparencia
- Uso: Header, login, register

### logo-white.png
- Tamaño recomendado: 200x50px
- Formato: PNG con transparencia
- Uso: Sidebar, footer

### dashboard-preview.png
- Tamaño recomendado: 1200x800px
- Formato: PNG o JPG
- Uso: Hero de portada

## Cómo agregar:

1. Crear las imágenes con las especificaciones
2. Colocarlas en esta carpeta: `public_html/assets/img/`
3. Los archivos PHP ya están configurados para usarlas
